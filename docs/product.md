# Nusend Product

Nusend is a single-user, self-hostable email orchestration product for AWS SES.

Core interfaces:

- HTTP API: source of truth for all product behavior.
- CLI: first-class thin HTTP client for operators, automation, and agents.

Nusend is not a hosted multi-tenant SaaS, visual editor, analytics dashboard, or campaign automation suite. It focuses on API-first sending orchestration, delivery state tracking, queueing, suppressions/unsubscribe handling, SES feedback ingestion, and predictable machine-readable errors.
